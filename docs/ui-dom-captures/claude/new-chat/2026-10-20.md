# claude.ai new chat, 2026-10-20

- Service: claude.ai web chat (not Claude Code), Korean UI, logged-in account, Chrome 155.
- Pages: `https://claude.ai/new` and `https://claude.ai/new?incognito`. Composer empty. Model menu and its 노력 submenu opened by hand; nothing was sent.
- Target behavior: open a new chat (incognito by default), optionally choose model and effort, insert the prompt, submit, confirm.
- Kind: reduced sketch. Attributes are copied from real outerHTML with class/style/id/svg removed. Menu row text is innerText with whitespace collapsed. Machine-readable copy: [2026-10-20.json](2026-10-20.json), which `docs/verification/claude-anchors.test.cjs` loads as its fixture.
- Not recorded: chat history, account name, plan, cookies.

## Elements used (anchor table in `src/content/claude.js`)

| Anchor | Observed | Notes |
|---|---|---|
| composer | `div[contenteditable=true][role=textbox][data-cds=Editor][data-testid=chat-input]`, `data-composer-editor="marlin"`, `aria-label="Claude에게 프롬프트를 입력하세요."` | Not ProseMirror/tiptap any more. `document.execCommand("insertText")` works: newlines become `<p>` paragraphs, `data-doc-empty` flips to `false` and the send button enables. |
| sendButton | `button[data-testid=chat-input-send][aria-label="메시지 보내기"]` | `disabled` while the composer is empty. |
| modelSelector | `button[data-testid=model-selector-dropdown][data-cds=ModelSelector][aria-haspopup=menu]`, `aria-label="모델: Opus 5.5 높음"` | Label = model name then effort word. Used to confirm both choices. |
| incognitoActive | `[data-testid=incognito-frame]`; button `aria-label="시크릿 모드 종료"` | Only on `?incognito`. The normal page has a button `aria-label="시크릿 모드 사용"` instead and no frame. |
| openMenu | `[role=menu][data-open]` (base-ui) | The 노력 submenu is a second `[role=menu]`. |
| menuRadio | `[role=menuitemradio][aria-checked]` | Model rows: Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 5.5, each with a description line. Effort rows: 낮음, 중간(추천 badge), 높음, 엑스트라, 최대(4× 이상 사용량 badge). |
| menuGroup | `[role=group]` inside the menu | Compact layout only: a tab whose viewport is 0x0 (opened but never shown) gets one flat menu with groups 모델 / 노력 / 더 많은 모델. The group's first text line is its label. The 최대 badge reads 5× for Sonnet, 4× for Opus. |
| submenuTrigger | `[role=menuitem][aria-haspopup=menu]` | Rows "노력 <current>" and "더 많은 모델". Older models under 더 많은 모델 are not offered. |
