# ChatGPT, Gemini, YouTube UI Observations: 2026-10-19

Source: signed-in Chrome (Profile 1) through Claude in Chrome, plus a logged-out isolated Chrome through Playwright for comparison. Capture type: reduced selector sketches and attribute lists, NOT exact outerHTML. Extension under test: v0.1.103 loaded from the Claude project folder. No prompts typed or sent. Menus were opened only to read them and closed with Escape; no selection changed. Chat titles, account names and other personal data were not recorded.

These are observations for 2026-10-19 only. Re-check the live page before relying on them later.

## ChatGPT (Temporary Chat new chat, ko UI with English effort labels)

Composer outside the menu changed:

| Purpose | Code expects (v0.1.103) | Observed 2026-10-19 |
|---|---|---|
| Composer form | `form[data-type='unified-composer']` | plain `form` without `data-type`; contains editor and submit |
| Editor | `#prompt-textarea.ProseMirror` (fallback `[contenteditable='true'][role='textbox']`) | `div.ProseMirror[contenteditable=true][role=textbox][aria-label="ChatGPT에게 물어보세요"]`, no `#prompt-textarea`; only the fallback matches |
| Model/effort trigger | `button.__composer-pill[aria-haspopup=menu]` | `button[aria-haspopup=menu][aria-label="ChatGPT 모델 선택"][data-composer-navigation-target=reasoning][data-codex-intelligence-trigger=true]`, `data-selected-reasoning-effort=max` while showing `Extra High`; no `__composer-pill` class |
| Send | `button[data-testid=send-button]`, `button#composer-submit-button` | `button[type=submit][aria-label="보내기"]`, no test id or id |
